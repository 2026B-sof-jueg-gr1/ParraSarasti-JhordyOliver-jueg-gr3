# ☀️ Cenit de Hierro

**Videojuego de plataformas 2D desarrollado con Phaser 3**

## 📖 Descripción del proyecto

*Cenit de Hierro* es un videojuego de acción y plataformas en 2D ambientado en un mundo de fantasía sumido en un eclipse perpetuo.

El jugador controla a **Aurel**, el último de los Forjadores del Mediodía, quien porta a **Áurea**, un hacha de guerra de enorme peso que utiliza fuerzas magnéticas para desplazarse por el entorno. Su misión es superar obstáculos, recuperar fragmentos solares y alcanzar la cúspide de la Aguja Celeste para devolver la luz al mundo.

## 🎮 Mecánicas principales

- **Movimiento y salto:** permite desplazarse horizontalmente y saltar entre plataformas.
- **Lanzamiento cargado:** el jugador puede mantener presionada una tecla para aumentar la potencia del lanzamiento del hacha.
- **Predicción de trayectoria:** muestra una estimación del recorrido del hacha, su rotación durante el vuelo y el posible punto de impacto.
- **Atracción magnética:** permite atraer a Aurel hacia el hacha y aprovechar la velocidad acumulada para impulsarse por el aire.
- **Superficies interactivas:** el hacha puede anclarse en superficies de piedra y rebotar en superficies metálicas.
- **Fragmentos solares:** objetos coleccionables necesarios para desbloquear el acceso al portal final.
- **Sistema de victoria:** el jugador debe reunir al menos tres fragmentos solares y alcanzar el portal situado en la cúspide.

## 🕹️ Controles del juego

| Tecla | Acción |
|---|---|
| `←` / `→` | Moverse a izquierda y derecha |
| `↑` o `Espacio` | Saltar |
| Mantener `X` | Cargar el lanzamiento del hacha |
| Soltar `X` | Lanzar Áurea |
| Mantener `C` | Activar la atracción magnética |
| `R` | Reiniciar la partida después de ganar |

## 🛠️ Tecnologías utilizadas

- **Phaser 3:** motor para el desarrollo del videojuego.
- **JavaScript:** implementación de las mecánicas, el movimiento y las interacciones.
- **HTML5:** estructura principal del juego.
- **CSS:** presentación y adaptación visual.

## 🎯 Objetivo del proyecto

Desarrollar un videojuego de plataformas 2D aplicando los fundamentos de programación de videojuegos, las físicas de movimiento, las colisiones, las fuerzas vectoriales y la interacción entre objetos.

El proyecto busca experimentar con una mecánica de desplazamiento basada en un arma que funciona simultáneamente como herramienta de combate y medio de movilidad, combinando lanzamiento, atracción magnética e inercia.

## 🌟 Características destacadas

- Escenario de fantasía con ambientación oscura y elementos luminosos.
- Física de movimiento con gravedad y colisiones.
- Sistema de carga para controlar la potencia del lanzamiento.
- Indicador visual de trayectoria estimada.
- Mecánica de atracción magnética para realizar desplazamientos aéreos.
- Obstáculos, plataformas y coleccionables.
- Objetivo final que incentiva la exploración y la precisión.
